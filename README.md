# Machine Learning Projects

This repository contains my hands-on Machine Learning projects using Python and PyTorch.

## Projects

### 1. Student Performance Prediction
A machine learning project that analyzes student-related factors such as study hours, attendance, assignments, previous scores, sleep hours, and screen time to predict final performance.

**Concepts used:**
- Pandas & NumPy
- Data Analysis
- Feature Engineering
- PyTorch
- Regression
- RMSE
- R² Score

### 2. Telemetry Analysis & Prediction
A machine learning project using telemetry data to analyze system conditions such as temperature, battery voltage, signal strength, current draw, rotation rate, packet loss, and solar current.

**Concepts used:**
- Pandas & NumPy
- Data Preprocessing
- Feature Engineering
- Label Encoding
- Train/Validation/Test Split
- Feature Scaling
- PyTorch

## Tools & Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- PyTorch
- Jupyter Notebook

## Purpose

These projects were built as hands-on practice to strengthen my understanding of Machine Learning, data preprocessing, feature engineering, and model development.
